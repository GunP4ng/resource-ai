# Re:Source AI: 한국 폐플라스틱 의사결정 지원용 공개 데이터 조사

조사 기준일: **2026-11-05**. 대상: 국내 사업장에서 배출하는 폐플라스틱의 분류 후보, 처리 경로 후보, 업체 탐색, 비용·온실가스 비교. 이 문서는 데이터 조사 결과와 MVP 설계 제안이며, 개별 폐기물의 법적 지위 또는 위탁 적법성에 대한 판정서가 아니다.

**조사 시점과 구현 상태 구분:** 아래의 “원본 미확보/행 미검증”은 최초 조사 당시의 기록이다. 같은 날 PR #15에서 가격 CSV, 울산 업체 비식별 파생본, 법령 제4조의2 텍스트를 확보·대조했다. 현재 확보 파일·해시·권리·누락 상태는 [출처 인계 상태](../data/sources/README.md), [manifest](../data/sources/manifest.json), [인계 문서](../data/sources/handoff-2026-11-06.md)를 기준으로 읽는다. 가격·업체 파일 확보가 별표별 법적 적용성, 현재 허가, 계산용 계수 확보를 뜻하지 않는다.

## 1. 바로 사용할 수 있는 결론

1. **가격·업체 탐색부터 시작할 수 있다.** 한국환경공단의 월별 재활용가능자원 가격조사는 CSV 컬럼과 단위가 확인되고, 공공누리 제1유형이 명시되어 있다. 전국폐기물처리업소표준데이터는 주소·업종·처리폐기물·영업구역·허가일자 등을 제공한다. 다만 가격은 폐플라스틱 처리수수료가 아니라 재활용가능자원의 시장가격이고, 업체 목록은 현재 허가증의 대체물이 아니다. [S1, S2]
2. **Allbaro는 이번 환경에서 본문 확보에 실패했지만, 순환자원 인정 상세 1건은 실제 확인했다.** 인정 상세에는 폐기물 코드·세부종류·사용용도·생산계획량·기간·기관·발급번호가 있다. 전체 코드표나 무인 수집 API가 있다고 가정하지 않는다. [S4, S5]
3. **현행 법령은 날짜별 버전을 고정해야 한다.** 공식 기본 URL과 실제 본문을 대조한 폐기물관리법 시행규칙은 `[시행 2026. 10. 2.]` 버전이며 제14조의3은 별표 5의3을 재활용 기준으로 연결한다. 별표 원문 전체와 이후 변경 유무를 완전히 대조하지 못했으므로, 제품에서 해당 날짜 기준 “법규 준수”를 자동 선언하면 안 된다. [S6]
4. **탄소 비교에 필요한 전체 계수 묶음은 없지만, GIR 전력계수의 실제 숫자·단위는 확보했다.** GIR 공식 PDF 1쪽에서 2023년 소비단 전력계수 0.4173 t CO2e/MWh 등을 확인했다. 이것은 플라스틱 재활용·소각·운송 전체 계수가 아니다. KEITI는 국가 LCI DB와 평가계수의 상업적 사용 불가를 명시한다. [S10, S11]
5. **비용 통계의 조사 정의를 원문으로 확인했다.** 가격조사 통계정보보고서는 물류비 제외·VAT 포함을 명시하고, 제주를 제외한 8권역 분류를 설명한다. 방치폐기물 단가 고시는 보험금·과징금 산정용이지 실거래 처리 견적이 아니다. [S8, S9]

## 2. 조사 방법과 검증 상태

- 1차 출처: 공공데이터포털의 제공기관 메타데이터, 한국환경공단 Allbaro·자원순환정보시스템·순환자원정보센터, 국가법령정보센터, 기후에너지환경부, 한국환경산업기술원, 온실가스종합정보센터, 통계청 자료.
- 실제로 읽은 범위를 아래에 구분했다. **웹 페이지 본문·컬럼 정의 확인**과 **원본 CSV 다운로드·행 검증**은 별개다. 이번 조사는 전자는 수행했으나 원본 CSV 전체 다운로드와 API 실호출은 수행하지 않았다.
- 국가법령정보센터 기본 화면은 동적 래퍼였으므로 HTML의 실제 iframe과 본문 경로를 추적했다. 잘못된 법령 식별자가 다른 법령을 반환한 경우 제외했다. GIR·통계청 PDF는 원격 바이트를 메모리에서 받아 `pypdf`로 추출했다.
- 검색 응답만으로 사실을 채택하지 않았다. 공개 목록이 있다는 사실만으로 라이선스, 현행 허가, 정확한 지리 범위, 완전성을 추정하지 않았다.
- 문서에 제시한 URL은 확인 경로다. 접속 성공은 당시 조회한 본문 범위의 성공이며, 전체 파일의 정상 다운로드나 상시 접근 보장은 아니다. 계정·인증키·개인 브라우저 탭은 사용하지 않았다.

### 증거 등급

| 등급 | 이 문서에서의 의미 | 허용되는 사용 |
|---|---|---|
| A | 공식 원문 본문 또는 명시적 스키마·메타데이터 확인 | 확인한 항목에 한해 사실로 표시 |
| B | 공식 요약·검색 노출·목록·첨부 존재 확인, 원자료 내용 일부 미확인 | 탐색 경로와 검증 대기 항목으로 사용 |
| C | 원자료 접근 실패 또는 단위·기간·권리 불명 | 수치 계산·적합 판정에서 제외 |

원문을 읽었다는 A 등급과 **재사용 허가가 확인되었다는 것**은 독립적이다. 한 기관의 동일 원문을 여러 포털에서 찾았다고 독립된 두 증거로 세지 않는다.

## 3. 데이터별 조사 결과

### S1. 한국환경공단_재활용가능자원 가격조사

- **소유·제공**: 한국환경공단 자원순환처 자원순환통계부.
- **원문**: https://www.data.go.kr/data/3076421/fileData.do
- **보조 조회**: https://www.recycling-info.or.kr
- **접근**: 공공데이터포털 파일데이터, CSV. 메타데이터와 컬럼 정의 본문을 실제 확인했다(A). 원본 CSV 행, 첨부 다운로드 URL, 과거 파일 전체는 미확보다. 공개 API는 확인하지 않았다. 화면 조회에 키는 필요하지 않았으며 파일 다운로드의 로그인 요구 여부는 미검증이다.
- **확인된 필드**: `시점`, `구분`, `수도권`, `강원`, `충북`, `충남`, `전북`, `전남`, `경북`, `경남`, `데이터 기준일`.
- **지리·조사**: 전국 및 8개 권역. 수도권은 서울·인천·경기. 매월 10일경, 10일 가격 기준의 조사를 설명한다. 단위는 **원/kg**. 권역 내 품목별 조사업체 가격의 평균이며 업체별 가격은 다를 수 있다고 명시한다.
- **품목**: 폐플라스틱은 PE·PP·PS·PET·ABS·PVC·EPS, 형태는 압축·플레이크·펠렛·잉고트 등을 설명한다. 본문에는 전체 조사품목 26개, 폐플라스틱 17개 항목으로 기재되어 있다. 수지와 형태의 모든 조합이 존재한다는 뜻은 아니다.
- **갱신·기간**: 월간. 확인 페이지는 등록·수정일 2026-10-26, 시간범위 **2026년 10월**을 명시한다. 11월 조사값이 있다고 가정하지 않는다. 과거 시계열의 시작일은 이 페이지에서 미확인.
- **라이선스**: **공공누리 제1유형, 출처표시**를 메타데이터에서 확인. 무료. 배포물에는 기관명·자료명·기준월·원문 링크를 보존한다.
- **MVP 경로**: 배출물의 수지·상품 형태·권역을 매칭한 **참고 매각가격** 카드. 사용자가 실제로 확보할 수 있는 판매가능 산출물량에 적용한다.
- **제약**: 2023년 통계정보보고서 S9는 물류비 제외·VAT 포함을 명시한다. 2026년에도 정의가 동일한지 최신 설명을 대조해야 한다. 혼합·오염 폐기물의 인수료·개별 전처리비·계약물량 할인은 이 시장가격으로 알 수 없다. 빈칸은 미공표 값이므로 0원으로 바꾸지 않는다. 펠렛 가격을 원료 폐기물 1톤에 바로 곱하지 않는다. 제주 사업장에 인근 권역 값을 자동 대입하지 않는다.

### S2. 전국폐기물처리업소표준데이터

- **소유·제공**: 지방자치단체, 공공데이터포털 표준데이터 통합 제공.
- **원문**: https://www.data.go.kr/data/15114147/standard.do
- **접근**: XLS·XML·JSON·RDF·CSV 형식을 메타데이터에서 확인(A). 전체 데이터 응답 또는 개별 다운로드 파일은 미확보. 공개 화면은 무키 조회 가능. JSON 표기만 보고 공개 REST API나 인증키 불필요를 단정하지 않는다.
- **확인된 항목**: `시설명`, `소재지도로명주소`, `소재지지번주소`, `위도`, `경도`, `업종명`, `전문처리분야명`, `처리폐기물정보`, `영업구역`, `시설·장비명`, `허가일자`, `전화번호`, `관리기관명`.
- **지리**: 지자체가 관리하는 전국 업체를 대상으로 한다. 실제 행별 누락률과 지자체별 최신성은 미검증이다.
- **갱신·기간**: 수시, 페이지 수정일 **2026-11-02**, 최초 등록일 2023-06-20. 최초 등록일은 각 업체 데이터의 최초 관측일이나 허가 유효시점이 아니다. 행별 기준일·폐업·변경허가 이력 존재 여부는 미확인.
- **라이선스**: 확인한 본문에는 무료와 “이용허락범위 안내” 링크만 보였다. **제한 없음/공공누리 특정 유형을 확인하지 못했으므로 라이선스 미확정**으로 둔다.
- **MVP 경로**: 주소와 좌표로 후보 업체를 좁히고 업종·처리폐기물정보·영업구역을 사람이 확인하는 업체 탐색.
- **제약**: 시설 좌표와 본사 주소를 혼동하지 않는다. 허가일자는 현재 영업·해당 코드 수탁 가능·여유 처리능력의 보증이 아니다. 좌표가 없으면 위치 미상으로 두며 지오코딩을 사용하려면 별도 서비스의 이용조건과 실제 시설 주소를 확인한다.

### S3. 울산광역시_폐기물처리업체현황: 지역 MVP용 구체적 대안

- **소유·제공**: 울산광역시 자원순환과.
- **원문**: https://www.data.go.kr/data/15054809/fileData.do
- **접근**: CSV 파일데이터. 메타데이터·컬럼 정의 확인(A), CSV 실제 행은 미검증. 공개 화면 무키, 파일 다운로드 로그인 여부와 API 제공은 미확인.
- **실제 스키마**: `구분`, `업체명`, `대표자`, `사무실 소재지`, `전화번호`, `영업구역`, `비고`. 페이지 설명에는 취급 폐기물·시설 정보를 언급하지만 **확인된 컬럼 정의에는 폐기물 코드·처리능력·시설 좌표가 없다**. 설명만으로 해당 필드가 있다고 만들면 안 된다.
- **지리**: 울산광역시 관내. 사무실 소재지가 처리장 위치와 같다는 보장은 없다.
- **갱신·기간**: 연간, 수정일 2025-12-22, 등록일 2019-09-20. 데이터가 2019~2025년 전체 시계열이라는 뜻은 아니다. 개별 행의 기준일은 미확인.
- **라이선스**: 메타데이터의 **이용허락범위 제한 없음**, 무료 확인.
- **MVP 경로**: 전국 자료의 재사용 권리 확인이 늦어지면 울산 범위의 업체 디렉터리로 축소. MVP에는 대표자명 등 불필요한 개인 필드를 가져오지 않는다.
- **제약**: 이 목록만으로 플라스틱 수탁업체 확정 불가. 허가범위 원문 및 업체의 현재 취급 가능 여부는 추가 확인이 필요하다.

### S4. Allbaro 폐기물분류번호·허가확인·전자 인계

- **소유·운영**: 한국환경공단 올바로시스템.
- **공식 입구**: https://www.allbaro.or.kr
- **접근을 시도한 분류 조회**: https://www.allbaro.or.kr/01_wsi/wsi_information_2023.vm
- **접근을 시도한 인허가 안내**: https://www.allbaro.or.kr/02_wga/wga_approval_02.vm
- **접근·키**: 웹 수집에서 본문이 비었고, 별도 HTTP 조회에서도 분류 경로는 상태 200·본문 0바이트였다(C). 실제 조회 필드·코드표·다운로드 UI·갱신일은 확인하지 못했다. 대외 공개 코드 API·키·로그인 조건도 미확인이다.

## 5. 비교 방법: 단위와 경계를 먼저 고정한다

아래는 **제품 설계 제안**이다. 계수가 없으면 아래 수식을 계산 가능한 것처럼 보이게 채우지 않는다.

### 5.1 기능단위·기준선

- 기본 기능단위: **배출 사업장 출구의 동일 상태 폐플라스틱 1톤(반입 습중량 기준)**. 실제 사례 총량은 별도 `input_mass_t`로 기록한다.
- 수지조성·수분·오염·이물·포장 상태와 측정 근거를 함께 기록한다. 산출물 수율이 건조중량 기준이면 건조중량과 수분을 별도로 변환한 후 적용한다. `1 t = 1,000 kg`를 명시적으로 변환한다.
- 기준선은 사용자 기존 위탁 경로 또는 증거 있는 대안으로 지정한다. **소각이 모든 배출물의 기본 기준선이라는 가정은 하지 않는다.** 기준선 미제공이면 경로별 계산 가능 항목만 표시하고 “감축량”을 주장하지 않는다.
- 비교 경계는 배출 지점 이후의 수거·중간 집하·선별·전처리·재활용/소각/기타 처리·잔재물 처리까지 맞춘다. 필요하면 원료 대체 효과를 별도 확장 경계로 표시한다. 폐기물이 되기 전 제품 생산의 부담은 별도 연구 목적이 없는 한 양 경로에 일관되게 제외한다.

### 5.2 비용: 참고가격, 견적, 제도 단가를 분리한다

경로 r에 대해:

`순비용_r[원/기능단위] = 운반비_r + 반입·처리수수료_r + 별도 전처리비_r + 잔재물처리비_r + 실제 적용 부대비_r - 실제 귀속 매각수입_r`

- 모든 항목에 가격 기준일, 원/톤·원/kg·원/회 등 원단위, VAT 포함 여부, 최소차량요금, 물량조건, 계약·견적 출처를 붙인다.
- S1 가격 적용 시 `수입 = 판매가능 산출물 kg × 해당 수지·형태·권역·월 가격[원/kg]`로 계산한다. 수율이나 판매가능 규격이 없으면 수입은 계산하지 않는다.
- 처리업체 견적이 운반·전처리·잔재물 처리를 포함하면 다시 가산하지 않는다. 산출물 판매수입이 처리업체에 귀속되고 사용자는 정액 처리비만 내는 계약이면 사용자 비용에서 판매수입을 임의 차감하지 않는다.
- 견적 유효기간·동일 물량·동일 품질·동일 경계를 맞추지 못한 가격은 순위를 매기지 않는다. 공공 통계 가격은 `참고 시장가격`, 실제 견적은 `계약 조건부 비용`, 고시는 `제도 산정용`으로 별도 표시한다.
- 확인한 공개자료만으로 **2026년 폐플라스틱의 일반 처리단가, 거리당 운송료, 모든 지역의 매각 순수입을 산정할 수 없다**.

### 5.3 탄소: 처리부담과 회피효과를 분리한다

`E_gross,r[kg CO2e/기능단위] = E_transport,r + E_sort/preprocess,r + E_treatment,r + E_residue,r`

`E_net,r = E_gross,r - Credit_material,r - Credit_energy,r`

`ΔE = E_net,baseline - E_net,r`

- 기본 화면에는 `E_gross`, 원료대체 크레딧, 에너지회수 크레딧, `E_net`을 분리한다. 음의 순배출이 나오더라도 “탄소 제거”라고 부르지 않는다.
- 공정계수가 `kg CO2e/t 반입물`이면 해당 공정 실제 반입 톤수를, `kg CO2e/kg 산출물`이면 해당 산출 kg을 곱한다. 계수 정의를 모르면 적용하지 않는다.
- 재활용 단계의 선별 손실·세척·건조·압출·첨가제·잔재물 처리를 확인한다. 이미 포함된 부담은 다시 더하지 않는다.
- 소각은 화석/바이오 기원 탄소 구분, 수분·조성·발열량·에너지 회수·잔재물 경계를 확인한다. “소각 1톤” 단일 계수를 수지·설비 구분 없이 적용하지 않는다.
- 모든 계수는 CO2만인지 CO2e인지, GWP 평가체계·기간(예: 100년), 가스 범위, 기준연도·지역이 맞아야 한다. 서로 다른 GWP 체계는 원가스 자료로 재특성화할 수 없으면 동일 차트에서 단순 비교하지 않는다.

### 5.4 운송

활동량 방식:

`E_transport = Σ(운송 질량[t] × 실제 도로거리[km] × 계수[kg CO2e/(t·km)])`

연료 실측 방식:

`E_transport = Σ(연료사용량[L 또는 kg] × 동일 연료·경계의 배출계수[kg CO2e/L 또는 kg CO2e/kg])`

- 둘 중 하나의 경계를 선택한다. 실측 연료에 이미 들어간 운송을 톤·km 방식으로 중복 가산하지 않는다.
- 집하·중간처리·최종처리·잔재물 구간별로 실제 적재 질량을 쓴다. 적재율, 공차 회송, 다중 배출처 공동수거의 할당, 차량·연료·규격, well-to-tank 포함 여부를 기록한다.
- 주소 간 직선거리는 후보 탐색용 하한·근사임을 표시할 수 있지만 도로 운송 탄소계산용 실제 거리로 확정하지 않는다. 경로 API 미확보 시 사용자 도로거리·운행일지 입력으로 전환한다.
- 확인한 이번 공개자료에는 **검증 완료한 운송 배출계수나 거리당 비용 계수가 없다**. 미확인 값은 0으로 넣지 않는다.

### 5.5 대체효과와 불확실성

`Credit_material = 판매가능 재생수지 kg × 대체율[kg virgin/kg recyclate] × 대체 대상 virgin 계수[kg CO2e/kg virgin]`

- 대체 대상 수지·품질·용도·시장과 실제 산출물 규격을 확인한다. 재생수지가 버진 수지를 항상 1:1 대체한다고 가정하지 않는다.
- 재활용·열회수의 크레딧을 폐기물 공급자와 재생원료 사용자 양쪽에서 동시에 전액 주장하지 않는다. cut-off, 할당, 대체법 등 방법을 선택해 공개한다.
- 대체율 근거가 없으면 **대체효과 제외 경계**를 먼저 제시한다. 제외한 결과를 완전한 순탄소 비교라고 부르지 않는다. 정책·계약 근거 없는 숫자 대체율을 낮음/중간/높음 시나리오로 만들어 넣지 않는다.
- 수율·오염·전력·거리·처리계수·대체율의 범위는 측정·문헌·견적에 근거해 등록한다. 검증된 최소·최대 범위가 있으면 범위 비교와 손익분기 거리 등을 계산하고 출처를 붙인다.
- 확률분포 근거가 있을 때만 상관관계를 보존한 확률 분석을 한다. 임의 ±20%를 붙이거나 근거 없이 정규분포를 만들지 않는다.
- 결과 범위가 겹치거나 누락 항목이 순서를 바꿀 수 있으면 `우열 불확실/추가자료 필요`를 반환한다. 비용·탄소·데이터 신뢰도를 임의 가중치로 한 점수에 숨기지 말고 각각 표시한다.

## 6. 결측·접근 불가·권리 미확인 시의 실행 가능한 MVP

### 6.1 우선 경로

1. **사용자 입력**: 발생 위치, 실제 중량·상태, 수지 추정 및 근거, 배출원, 오염/이물, 기존 처리, 희망 산출물. 코드 미확정은 그대로 미확정으로 저장.
2. **법령 근거 탐색**: Allbaro·법령·순환자원 인정/지정 자료를 링크한다. 미검증 조건에는 추가 질문과 원문 확인 항목을 반환한다.
3. **업체 후보 검색**: 권리 확인된 전국 자료 또는 울산 자료에서 후보를 표시. “거리순 후보”는 가능하지만 “최저탄소·허가 적합 업체”로 표현하지 않는다.
4. **시장가격 카드**: S1의 확인된 최신 기준월·수지·형태·권역만 조회. 매칭 실패·미공표는 `null` 및 원인을 표시한다.
5. **비용 비교**: 사용자가 보유한 실제 견적을 같은 경계로 정규화한다. 미제공이면 `견적 필요`와 필요한 비용 항목을 출력한다.
6. **탄소 비교**: 사용권·단위·경계가 승인된 계수와 활동량이 있는 경로만 계산한다. 하나라도 핵심 계수가 없으면 `계산 불가`와 확보할 자료를 제시한다. 시연을 위해 가상 비용·계수를 사실처럼 넣지 않는다.

### 6.2 필요한 데이터 계약

아래는 신규 구현 제안이며 원자료의 실제 컬럼명 주장이 아니다.

- `source`: 기관, 자료명, 원문 URL, 조회시각, 게시일, 자료 기준일, 파일 해시(실제 파일 확보 후), 권리 조건, 원문 위치.
- `legal_evidence`: 문서명, 공포·시행일, 적용 종료/개정 여부, 조항·별표·행, 인정번호·유효기간, 확인자, 미검증 이유.
- `facility`: 원자료 업체 ID, 시설/사무실 구분, 주소·좌표, 허가 근거·확인일, 처리종류, 후보 상태. 상호만으로 중복 병합하지 않는다.
- `price`: 가격 유형, 수지·형태, 지역, 월, 통화·단위, VAT·경계, 유효기간, 결측 사유.
- `factor`: 값·단위, 물질/공정, 지역·기술·기간, 경계, 포함 항목, GWP, 할당·대체법, 불확실성, 라이선스, 검토 상태.
- `calculation`: 기능단위, 입력 출처, 버전 고정된 근거·계수, 단위 변환, 포함·제외 항목, 미계산 항목, 범위·민감도, 결론 보류 이유.

공개·무키 조회, 파일 다운로드 가능, API 사용 가능, 상업적 재사용 가능은 네 개의 독립 상태로 관리한다. `unknown`을 `false` 또는 `true`로 자동 치환하지 않는다.

## 8. 이번 조사에서 남은 공백과 다음 확보 순서

1. **법령 별표·고시 전문**: 2026-11-05 유효본과 부칙, 연결 고시를 확보해야 세부 처리규칙을 데이터화할 수 있다. 현재 문서는 조문 연결과 일부 버전만 확인했다.
2. **Allbaro 전체 코드표**: 코드·명칭·상하위 관계·개정일·사용조건을 원본으로 확보. 공개 화면 예시를 전체 플라스틱 코드표로 확대하지 않는다.
3. **업체 행 검증**: 전국 표준자료 라이선스, 실제 행별 기준일·좌표 품질·휴폐업·허가범위를 확인. 울산은 라이선스가 명확하지만 세부 코드가 없다.
4. **가격 원본**: 2026-10 CSV 다운로드 후 인코딩·빈칸·수지/형태 코드·날짜·중복을 검사. 원문과 다른 숫자가 없는지 일부 행 대조. 현재 컬럼·단위는 확인됐지만 실제 CSV 행 검증은 안 했다.
5. **비용**: 사용자 실제 견적 확보가 우선. 거리·차종·정액 최소요금이 반영된 운반비와 수탁 처리비가 없으면 순비용 순위는 내지 않는다.
6. **탄소**: GIR 전력계수 숫자는 확보했지만 상용 사용권·적용 체계는 별도 확인이 필요하다. KEITI 이용권한과 공정별 레코드, 적합한 운송·처리·대체 계수는 미확보다. **검증된 전체 폐플라스틱 경로 탄소계수 묶음은 없다.**

## 9. 최종 검증 범위

- 데이터명·기관·URL·파일/API·키 여부·실제 확인 필드·지리·라이선스·주기·기간·MVP 제약을 S1~S12에 각각 기록했다. `미확인`은 자료가 없다는 뜻이 아니라 이번 조회로 검증하지 못했다는 뜻이다.
- 공공 CSV 전체 다운로드·인증키·유료/비공개 자료·개인 브라우저·외부 메시지는 사용하지 않았다. 공개 GIR·통계청 PDF 바이트는 메모리에서 파싱했으며 디스크에 남기지 않았다. 공공 API가 동작한다거나 실제 30건을 확보했다고 주장하지 않는다.
- 연구 산출물은 이 파일 하나다. 이 조사 과정에서 소유 임시 루트를 만들거나 다운로드 파일을 남기지 않았으므로 별도 삭제 대상은 없다.
- 실무 적용 직전 다시 확인할 것은 **법령의 날짜별 유효성, 개별 인정·허가의 현재 상태, 데이터 사용권, 실제 견적, 탄소계수의 단위와 경계**다. 모델의 추론은 이를 대체하지 않는다.
