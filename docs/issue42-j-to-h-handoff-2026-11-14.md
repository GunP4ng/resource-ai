291947 운영 변경은 [원격 작업 브랜치 `work/j2-291947-currentness`](https://github.com/GunP4ng/resource-ai/tree/work/j2-291947-currentness)의 `7ba5c11`에, 이 문서의 최초 인계는 `0e0813a`에 게시했다. **`main`에는 아직 병합하지 않았다.** H는 작업 브랜치의 원본과 출처를 직접 열 수 있지만 기본 브랜치에서 같은 조회 결과가 나온다고 가정하지 않는다. `bun test tests/legal-registry.test.ts tests/h-candidates.test.ts`는 날짜 경계와 H 후보 보류 상태를 확인한다. H의 합성 후보 10건(평가일 11/12)에는 일반 조문·공통 별표 참고 인용이 반환되지만, 특정 51-03-01 코드·R-3-3 인용은 0건이다. 그 날짜나 참고 인용만으로 실제 현장 사실 또는 적합성을 확정하지 않는다. 특히 공정·수지·오염·유해 접촉·발생 사업장/허가를 사례별로 대조해야 한다. 영어 자유 서술이나 사진 수지 후보는 구조화된 법령 적용 사실로 치환하지 않는다.

2026-11-15 후속: [현행성 재확인 기록](../data/reference/legal/291947/README.md)에 따라 구 시행본의 적용은 11/11 종료, 신 시행본의 인용 확인은 11/15까지다. 팀장 #57의 기존 인용 7건 11/14 확인 이력은 삭제하거나 11/11로 낮추지 않는다. 11/16 이후는 다시 보류하며 H의 사례별 검토 요구는 그대로다. `main` 병합 여부는 별도 확인이 필요하다.

## 후보 30건: 출처와 임시 그룹

J 개발 후보 10건의 공개 자료는 별도 원격 브랜치 [`4501cc7`의 J 후보 인계](https://github.com/GunP4ng/resource-ai/blob/4501cc769e9c22c4358c1c42552d2f6e4a2cb7fa/data/candidates/j-2026-11-13/README.md)에 있다. `manifest.json` SHA-256은 `c1911c47f21ded15c13178c81cd4a09f1c9ab535afda2b0ed2df4211f47e4452`이고, 각 후보는 서로 다른 Wikimedia Commons **파일 페이지**를 임시 그룹(`commons-page-*`)으로 삼는다. 10개는 실제 현장 사례가 아닌 사진 메타데이터에 연결된 **미상/합성 입력**이다. 사진 원본 10개는 다운로드하지 않아 사진 바이트 SHA-256과 서버 `photoRef`가 없고 모델 전송 승인도 없다. 메타데이터·입력 JSON 해시는 사진 원본 해시가 아니다.

세 트랙의 manifest를 [J의 AI 보조 교차검토](https://github.com/GunP4ng/resource-ai/blob/4501cc769e9c22c4358c1c42552d2f6e4a2cb7fa/data/candidates/j-2026-11-13/peer-source-review.json)에 적힌 SHA와 다시 대조했다: J `c1911c47…e4452`, H `df62053c…9e68`, O `95be89c0…fbd4`가 일치한다. 현재 공개 개발 후보는 J 10, H 10, O 10이다. H의 출처 그룹은 6개(그중 5개가 같은 업로더의 임시 코호트), J는 공개 파일 페이지 10개, O는 사진/외부 출처 없는 합성 시나리오 10개다. O manifest의 10개 개별 그룹을 인수 승인으로 보지 않고, 교차검토는 향후 분할에서 **한 저작 코호트**로 보수적으로 묶도록 제안한다. 따라서 6+10+1=**17개 임시 그룹**이며, 기존 O manifest나 H manifest 자체를 변경하지 않는다.

J/H 간 정확히 같은 공개 파일 페이지 URL은 관찰되지 않았다. 이것은 같은 현장·배치, 의미상 중복이나 사진 변형이 없다는 증거는 아니다. `peer-source-review.json`은 AI 보조 출처 비교이며 수집자가 아닌 두 사람의 독립 그룹 검토, 라벨, 18개 개발/12개 잠금 배정은 모두 **미완료**다. H 후보의 사진 설명·표시 재질과 J 후보의 Commons 제목도 공정·오염·법률 적합성의 독립 근거가 아니다. 현장 사례 0건, 독립 사람 라벨 0건, 잠금 평가 사례 0건을 유지한다.

## H/O가 사용하기 전에 필요한 연결

1. H는 J의 공개 후보를 실제 승인된 사진으로 간주하거나 모델에 전송하지 않는다. 필요한 경우 출처 원본/파생 바이트의 SHA, 목적별 사용권·동의·철회와 정확한 actor/case/revision의 권한을 먼저 확보한다. H의 공개 사진 10장은 별도 권리 기록이며 J 후보 10장의 사진 바이트/권한을 대신하지 않는다.
2. H가 J 법령 결과를 후보에 연결할 때는 평가일·공정·수지·오염/유해 접촉·원본 `sourceId`·locator·SHA와 `issues`/`reviewRequirements`를 함께 전달한다. 부분 인용을 사실 전체의 승인이나 `eligible` 결과로 승격하지 않는다. 11/16 이후에는 원문 현행성 재확인이 먼저다.
3. O의 자료 `check/install`에는 정확한 actor/case/revision, 실제 사업장·시설 허가/인수, 질량 측정, 계약 견적/계수, 원본-파생 계보와 승인 범위가 필요하다. 지금의 J 공개 후보·법령 발췌만으로는 설치 가능한 현장 package가 없다. 미확보 비교값은 `unavailable`로 남긴다.
4. 팀장과 자료 제공자는 비공개 전달 경로와 자료별 사용/보관/모델 전송 범위를 정하고, 두 독립 검토자의 그룹·라벨 검토와 불일치 조정 후에만 개발/잠금 분리를 승인한다. 원본 사진·개인정보·사업장 민감 자료는 공개 이슈나 이 문서에 넣지 않는다.

인계 확인점: 이 문서와 J 후보 브랜치의 검토 경계는 [#42 H 인계 댓글](https://github.com/GunP4ng/resource-ai/issues/42#issuecomment-6879352876)에서 공유했다. 새 법령 운영 변경은 원격 작업 브랜치에 게시됐으나 `main`에는 미병합이다. #42의 현장 제공자·권한·실자료 인수 체크박스는 이 문서와 댓글만으로 완료되지 않는다.
