# #13 공개 근거 공급: 적용 범위와 남은 보류

2026-11-15. 대상은 기존 노출 개발셋 18건이며, 새로운 현장 표본·사람 라벨·미노출 holdout은 없다. `data/evaluation/development.json`과 원래 입력은 바꾸지 않았다.

`data/evaluation/public-evidence-20261115.json`에 18건의 직전 사유를 원문으로 보존하고 공개 원문으로 해결할 부분, 공개 규정과 현장 적용을 함께 확인할 부분, 현장·업체만 제공할 부분으로 분류했다. 여섯 깨끗한 후보에는 원래 입력 revision, 법령 sourceId, 코드 수준 업체 후보, 부분 계산값을 연결했다.

## 실제 판정에 연결한 근거

기존 `data/sources/manifest.json`과 `evidence-candidates.json`을 사용한다. `src/evidence.ts`, `src/assessment.ts`, `src/domain.ts`, 세션 및 평가 러너의 로직·임계값·필수 검토 조건은 변경하지 않았다.

- 기존 `legal-290881-annex4-code`, `legal-290881-annex4-2-r3-3`, `legal-290881-annex4-3-types`의 정확한 검색 문자열에 여섯 후보의 공정 서술과 PET/HDPE/LDPE를 추가했다. 원문은 PVC 제외 폐합성수지 및 R-3-3을 PP/PE 사출·압출에만 한정하지 않는다. 발생공정을 재활용 공정으로 간주하지 않으며, 사업장일반폐기물 해당 여부와 지정폐기물 제외·실제 공정·용도·허가·인수 검토 조건을 유지했다.
- `legal-public-annex5-4-obligations`: 별표 5의4 제1호가목1), 제2호가목2), PDF 1–2쪽. 오염방지와 분말·미립자 등의 비산·유출 방지 보관 의무다. 시설이 이를 충족했다는 증명은 아니다.
- `legal-public-annex5-3-r3-3-packaging`: 별표 5의3 제2호나목1)다)(1)(가)·(나), PDF 6쪽. 열거된 폐포장재 등의 선별·압축·감용·절단에 대한 적용 범위와 이물질·유해물질 분리 조건을 발췌했다. 공정 자투리를 자동으로 재활용의무대상 폐포장재로 분류하지 않는다.

별표 5의3은 재활용 기준, 별표 5의4는 재활용자의 준수사항이다. 둘을 같은 별표로 표기하지 않는다. 새 발췌의 `verifiedThrough`는 2026-11-15이고, 기존 인용의 2026-11-14 현행성 경계는 그대로다. 현재 평가일인 2026-11-10/12는 모두 그 안에 있다. 이번 검색 범위는 노출된 여섯 입력을 검토한 결과이며, 일반 자연어 이해나 독립 정확도 개선으로 주장하지 않는다.

`등록` 표시는 현행 허가 검증이 아니다. 괄호 숫자는 원문 처리방법 코드이며 허가연도로 해석하지 않는다. 지역·코드 기반 탐색 후보를 여섯 사례에 연결했지만, 그 업체가 해당 지역에 서비스를 제공하거나 정확한 수지·형태·오염도의 물량을 인수한다는 주장은 하지 않는다.

공식 허가명부의 실제 업체 행은 확보하지 못했다. [경기도 처리업 현황](https://www.data.go.kr/data/15057767/openapi.do)은 원 제공기관 응답이 데이터 영역 전에 끝났고, [환경공단 재활용실적 및 업체현황](https://www.data.go.kr/data/15105969/fileData.do)은 확인한 공개 열이 폐기물별 집계였다. [화성시 현황](https://www.data.go.kr/data/3046882/fileData.do)의 확인한 열에는 코드가 없었다. 이는 이번 취득 한계이며 전국 공개자료의 부재를 의미하지 않는다.

회원자료는 상업 이용·재배포 권리가 확인되지 않아 `licenseVerified=false`, `localPath=null`로 등록했다. 회사명·지역·코드 탐색 정보만 연결하고 원문 HTML은 제품에 번들하지 않았다. 관할기관의 원 허가증·변경내역·현재 영업상태와 업체의 인수 의사·용량·견적이 필요하다. 검증된 시설 후보를 만들어 `DomainResources.processors`에 넣지 않았다.

## 비용·탄소: 부분 계산만 공급

**공개 자료 기반 계산값(관측값 아님)**. 선행 2단계의 골판지 매각가격·WARM 탄소계수는 플라스틱에 전용하지 않는다. 원주 반입료와 폐아스콘 운임도 실제 플라스틱 계약값으로 쓰지 않는다.

2단계의 수집 10,000원/t, 선별 20,000원/t, 운송 300원/(t·km), 거리 30km라는 가정만 명시적으로 재사용한다. 질량은 기존 합성 입력값이며 실측이 아니다. `m=massKg/1000`일 때 가정된 수집·선별·운송 소계는 `m*(10000+20000+30*300)`이다.

## 직전 판정 재현과 회귀 범위

직전은 PR #58 후 실제 C 18건이며 compared 0, needs-review 16, needs-information 2였다. 데이터 변경 전후 비교는 동일 원본 입력을 유지한다. 법령 근거만 실제 C의 기존 조회 경로에 들어간다. 회원등록·부분 계산은 검토자료로 연결하되 실제 허가·견적·경로 검토로 주입하지 않는다.

새 근거가 기본 조회에 포함되므로 공개 개발 패키지 두 개의 캐시를 기존 `o-public-data.ts prepare`와 `o-public-images.ts prepare`로 재생성했다. 검증 코드는 그대로이며 각 `verify`를 실제 실행했다. 만료 테스트는 새 검증기간 다음 날인 2026-11-16을 사용하고, 패키지 테스트는 비어 있던 근거 대신 새 발췌 두 개와 원문 PDF 두 개가 검증 상태로 보존됨을 확인한다. 기존 거부·변조·승인 대기 조건은 제거하지 않았다.

실구독 재실행 결과와 전체 검사 영수증은 [평가 보고서](hold-fix-evaluation-20261115.md)에 기록했다. C는 compared 0, needs-review 15, needs-information 3이며 OYS-003만 질량 정보요청으로 전환됐다. 전체 테스트는 823 pass/0 fail, typecheck·build는 통과했다.
