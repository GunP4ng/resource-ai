## 결과와 측정 범위

외부 모델 호출은 **0회**다. 실제 `requestBridge` → `createResourceApp` → 입력 검증 → host 판정 → 사례 저장/보고서 경로를 사용했다. 구조화된 사실·평가일은 원본 그대로이고 사진은 기존 `loadDevelopmentManifest`와 같이 전송하지 않는다. 서버가 새로 발급한 사례 ID는 `originalId`와 연결했다.

이는 현재 host의 추천/보류 원인 측정이다. 과거 `scripts/eval-development.ts` A/B/C 실구독 평가를 다시 실행한 것이 아니며 모델 응답 오류·추가 보류·사용량을 검증하지 않는다. 그 CLI의 실행 모드는 `RESOURCE_MODEL_RUNNER=subscription`만 허용하고 `local`은 호출 전에 거절한다. 내보낸 `runDevelopment` 함수도 실구독 실행용이며 로컬 모드는 없으므로 이번 측정에 사용하지 않았다.
