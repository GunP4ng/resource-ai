# 추천 목표와 실행 전 확인 기준 (2026-11-15)

소유자가 재정의한 목표는 **기업 부산물(사진·설명)의 재사용·재활용·처리 경로를 비교·추천하여 판단을 돕는 것**이다. 법령 근거, 처리업체 후보, 비용, 탄소를 같은 보고서에서 설명한다. 반출·계약·현장 실행의 승인 여부를 판정하는 제품이 아니다.

이 문서는 앞으로의 설계·완료 기준이다. 현재 코드의 상태명이나 게이트가 이 기준을 모두 구현했다고 주장하지 않는다. 추천 모드 코드와 연결한 실제 앱 실행 증거는 별도 인계 대상이다. 과거 문서의 실행 결과·미완료 체크·SHA·수량은 해당 실행 시점의 사실로 보존한다.

## 차단과 확인 목록의 경계

| 관찰 | 추천에서의 처리 | 반드시 남기는 내용 |
| --- | --- | --- |
| 지정폐기물·유해물질 의심 | 위험 경로 추천 차단, 필요한 확인 요청 | 의심 근거, SDS/분석 등 확인 항목과 담당자 |
| 법령상 명백히 금지된 경로 | 해당 경로 제외 | 검증된 조문·시행일·원문 위치와 적용 이유 |
| 출처 없는/검증 실패 인용 | 해당 주장·추천 근거로 사용 금지 | 미확보·만료·불일치 이유, 확보할 근거. 필수 근거를 검증할 수 없으면 해당 추천 차단 |
| 입력 모순 | 모순에 의존하는 추천 차단 | 서로 충돌하는 입력과 확인 질문 |
| 허가 유효성·업체 인수/계약 미확인 | 확인 필요 업체 후보로 표시하고 경로 비교 계속 | 목록 등재와 허가/인수 확인의 차이, 조회일, 실행 전 확인 담당 |
| 실제 견적·실측 질량·거리 미확보 | 확인 가능한 항목만 비교, 공개 근거·합성 가정을 구분 | 수치의 출처·단위·기간·범위, 미계산 항목 및 실제값 확인 필요 |
| 탄소계수의 현장 적용 검토·현장 승인 미완료 | 적용 범위를 명시한 시나리오 비교와 확인 목록 | 계수/GWP·지역·기술·경계·제외 항목, 현장 적용 검토 필요 |

미확인을 적합·불법으로 확정하지 않는다. 법적 코드가 미확정이어도 검증된 근거와 명시한 조건으로 가능한 대안을 비교할 수 있다. 법령 금지 여부를 판정할 핵심 근거 자체가 미검증인 경우와, 검증된 일반 근거를 현장에 적용하기 전 확인이 필요한 경우를 구별한다.

사진만으로 화학성분·유해성·법적 코드를 확정하지 않는다. 자료 권리·개인정보·사용자 동의·모델 전송 권한·사례 소유권·감사/사용량 경계는 그대로 적용한다. 여기서 실행 전 확인으로 옮기는 것은 폐기물 반출·처리의 현장 확인이며, 사진 전송 동의를 생략하는 지시가 아니다.

## 보고서의 최소 내용

1. 가능한 경로와 제외 경로, 각각의 이유·법령 출처·조건을 제시한다.
2. 확인된 출처가 있는 업체 후보를 제공하고 허가 유효성·인수 미확인을 표시한다. 명백한 부적합 후보는 제외한다. 후보가 없으면 미확보를 적고 경로 비교는 유지한다.
3. 비용·탄소를 확인 가능한 항목별로 비교한다. 같은 기능단위·경계를 만족하면 범위/Pareto 순위군을 제시한다. 겹침·상충·결측이면 해당 수치 순위의 한계를 적으며 가능한 경로의 조건별 장단점을 계속 설명한다.
4. 허가 유효성, 업체 인수·계약, 실제 견적·질량·거리, 탄소계수 적용 검토, 현장 승인 각각에 확인 상태·확인할 자료·담당을 적는다. 담당을 모르면 미정으로 남긴다.
5. 공개 참고자료·합성 가정·현장 확인 사실을 분리한다. 공개 자료 기반 계산은 **시나리오 추정, 현장 미검증**이라고 표시한다. 자료 없는 값·확률·감축량·업체를 만들지 않는다.

`compared`는 근거 있는 경로 비교를 사용자에게 산출한 상태로 평가하며 실행 허가로 해석하지 않는다. 특정 수치의 `unavailable`, 우열 불확실, 실행 전 확인 필요는 보고서 안에 공존할 수 있다. 현재 구현의 엄격한 수치 순위 계약은 별도로 기록하며 문구만 바꿔 기존 결과를 `compared`로 재분류하지 않는다.

## 공개 자료와 일정

현장 자료는 받지 못하는 것으로 확정됐다(#42). 권리 확인된 공개 사진·공개 원문과 명시한 합성 공정/질량/거리 가정을 사용한다. 미검토 ZIP 700장이나 현장 package를 기다리는 항목은 개발·데모의 선행 조건에서 제거한다. 공개 사진의 사용권도 파일별로 확인하고 모델 전송 동의는 별도로 지킨다.

2026-11-20 기능 동결, 11월 25일 발표 일정과 담당자는 유지한다. 공개·합성 자료로 추천 완주와 안전 차단을 각각 시연하고, 현장 성능·독립 사람 정답·미열람 잠금 평가를 확보한 것처럼 발표하지 않는다.

평가의 분모·독립 라벨·추천 산출률·차단 정확도·추천 순위·확인 목록 기준은 [평가 계획](evaluation.md)을 따른다.
