# 11월 25일까지 실행 계획

기준일 2026-11-05. 아래 역할은 기술 숙련도 미확인 상태의 **제안 배정**이며 첫 팀 회의에서 조정한다.

| 담당 | 소유 경계 | 첫 산출물 | 인수 조건 |
|---|---|---|---|
| 이태용(팀장, 모지리 지원) | 구조/통합 검토·Azure·통합 테스트·잠금 평가 실행·최종 보고서/영상·발표·운영진 확인 | ADR, 권한/배포 확인, 통합 실행 기록·보고서/영상 초안 | 통합 시나리오·잠금 평가 기록·릴리스 체크·최종 보고서/영상·제출 확인 |
| 윤정준 | 출처 수집·정규화·검색·법령 버전 | 출처 manifest, 코드/규정 lookup | 원문 위치·시행일·라이선스·최신성 기록 |
| 이상협 | 분류/추가질문·대안 판단·도구 어댑터 | 정상/보류 상태 계약 | 사진 단독 확정 금지, 누락·위험 사례 보류 |
| 오연석 | 업체·비용/탄소·앱/조건부 보고서 화면·데모 연결 구현 | 후보 필터, 단위 있는 비교표, 상태별 화면 | 근거 없는 수치/업체 배제, 자기 기능 테스트·실행 증거 인계 |

공통 계약은 `src/contracts.ts`에서 먼저 합의한다. 데이터 담당은 계약의 manifest와 조회 응답만, 판정 담당은 입력/상태와 도구만, 비교 담당은 대안/계수와 앱/보고서 화면만 변경한다. 공통 타입 변경은 팀장 리뷰 후 모두에게 알린다. 예시 데이터는 실데이터가 아니다. 팀원 각자의 모듈 단위 테스트는 구현 완료 기준으로 유지하고, 통합 테스트·개발 실험 실행/집계·잠금 평가·시연 전 검증과 최종 보고서·영상 제작은 이태용(모지리 지원)이 책임진다. 세부 구현 배정은 [팀원별 작업](team-tasks.md)을 따른다.

> **2026-11-12 정정:** 이 계획의 Azure 항목(R01 Azure 배포/권한, R09 Azure 추적 표시, 11/5~6 최소 Azure 호출)은 작성 당시 계획이다. 2026-11-06 소유자 결정으로 앱 기본 실행 공급자는 senpi `chatgpt-subscription` / `gpt-6-sol`로 바뀌었고 Azure는 `RESOURCE_MODEL_RUNNER=azure` opt-in 경로로 남았다(`scripts/app.ts`, `src/session.ts`). 해당 항목은 승인된 구독 계정의 실행·추적·사용량 확인으로 읽고, Azure는 선택 시에만 확인한다. 실제 구독 호출 성공은 아직 인수되지 않았다. 표의 원문은 기록으로 남긴다.
