# 제출·발표 실행 계획

기준일 2026-11-05. 아래 역할은 기술 숙련도 미확인 상태의 **제안 배정**이며 첫 팀 회의에서 조정한다.

**2026-11-20 인수 정정:** 현재 팀 일정은 11/20 동결·평가·백업 준비, 11/21 최종 정리, **11/22 제출**, 11/25 발표다([#66 일정](https://github.com/GunP4ng/resource-ai/issues/66#issuecomment-6953508232)). 아래 초기 일정의 11/23 최종본·11/25 업로드 계획을 제출 마감으로 사용하지 않는다. 공식 업로드 시각·파일 형식은 별도 확인 대상이다.

분류·경로 판단은 H에서 J로 이관됐다([#6](https://github.com/GunP4ng/resource-ai/issues/6#issuecomment-6896428666)). 아래 초기 담당 표보다 해당 이슈의 현재 담당과 인계 기록을 우선한다.

최종 시연은 사진 없이 공개·합성 텍스트로 정상 추천 3분, 유해 접촉 보류 2분을 보여주고 질량 누락 질문을 보조한다([#12](https://github.com/GunP4ng/resource-ai/issues/12#issuecomment-7033383035), [#55](https://github.com/GunP4ng/resource-ai/issues/55#issuecomment-7029699997)). 로컬 데모는 외부 모델 호출이 없으며 실제 구독 호출 증빙을 대신하지 않는다. H 교차검토 수락은 전체 잠금 평가 완료나 독립 정확도 입증과 구분한다([#13](https://github.com/GunP4ng/resource-ai/issues/13#issuecomment-7029699568)).

**2026-11-15 목표·일정 갱신:** [추천 목표](recommendation-goal.md)가 현재 인수 기준이다. #42에 따라 현장 자료·실사진 대기는 종료하고 권리 확인된 공개 자료·합성 사례로 진행한다. 과거 일정의 날짜와 실행 기록은 이력이며 현재 남은 작업은 11/20 기능 동결 전 비교·추천 완주와 안전 차단 확인이다. 11/25 발표와 기존 담당자는 유지한다. 현장 확인·실견적·계수 적용 검토는 실행 전 확인 목록으로 인계한다.

| 담당 | 소유 경계 | 첫 산출물 | 인수 조건 |
|---|---|---|---|
| 이태용(팀장, 모지리 지원) | 구조/통합 검토·Azure·통합 테스트·잠금 평가 실행·최종 보고서/영상·발표·운영진 확인 | ADR, 권한/배포 확인, 통합 실행 기록·보고서/영상 초안 | 통합 시나리오·잠금 평가 기록·릴리스 체크·최종 보고서/영상·제출 확인 |
| 윤정준 | 출처 수집·정규화·검색·법령 버전 | 출처 manifest, 코드/규정 lookup | 원문 위치·시행일·라이선스·최신성 기록 |
| 이상협 | 분류/추가질문·대안 판단·도구 어댑터 | 정상/보류 상태 계약 | 사진 단독 확정 금지, 누락·위험 사례 보류 |
| 오연석 | 업체·비용/탄소·앱/조건부 보고서 화면·데모 연결 구현 | 후보 필터, 단위 있는 비교표, 상태별 화면 | 근거 없는 수치/업체 배제, 자기 기능 테스트·실행 증거 인계 |

공통 계약은 `src/contracts.ts`에서 먼저 합의한다. 데이터 담당은 계약의 manifest와 조회 응답만, 판정 담당은 입력/상태와 도구만, 비교 담당은 대안/계수와 앱/보고서 화면만 변경한다. 공통 타입 변경은 팀장 리뷰 후 모두에게 알린다. 예시 데이터는 실데이터가 아니다. 팀원 각자의 모듈 단위 테스트는 구현 완료 기준으로 유지하고, 통합 테스트·개발 실험 실행/집계·잠금 평가·시연 전 검증과 최종 보고서·영상 제작은 이태용(모지리 지원)이 책임진다. 세부 구현 배정은 [팀원별 작업](team-tasks.md)을 따른다.

> **2026-11-12 정정:** 이 계획의 Azure 항목(R01 Azure 배포/권한, R09 Azure 추적 표시, 11/5~6 최소 Azure 호출)은 작성 당시 계획이다. 2026-11-06 PR #25에서 앱 기본 실행 공급자를 senpi `chatgpt-subscription`으로 바꿨고, PR #26에서 기본 모델을 `gpt-5.5`에서 `gpt-6-sol`로 바꿨다. Azure는 `RESOURCE_MODEL_RUNNER=azure` opt-in 경로로 남았다(`scripts/app.ts`, `src/session.ts`). 해당 항목은 승인된 구독 계정의 실행·추적·사용량 확인으로 읽고, Azure는 선택 시에만 확인한다. 실제 구독 호출 성공은 아직 인수되지 않았다. 표의 원문은 기록으로 남긴다.
