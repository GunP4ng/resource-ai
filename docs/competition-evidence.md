## 의무·권장·설계 판단을 구분한다

주제 PDF p.3은 공개데이터로 폐기물·부산물을 분석하여 산업 자원순환 의사결정을 지원하는 agent 서비스를 요구한다. 식별→재활용 가능성→규정→활용 기업→비용·탄소 비교→최적안은 제시된 흐름이다.

소개영상 05:24–05:35는 agent 자체 또는 이를 지원하는 MCP 서버도 방안이라고 설명한다. 특정 “senpi plugin”이나 “Foundry hosted Agent Service”가 의무라는 근거는 없다. 08:47–09:35는 화려한 UI보다 창의적인 작은 해결책과 기술을 차근차근 쌓아간 과정을 강조한다.

OT p.4는 Azure VM/ML/AI, Copilot Enterprise와 교육 커리큘럼을 안내한다. **열거된 모든 서비스를 제출물에 반드시 포함해야 한다는 문구와는 다르다.**

1주차 00:03:07–00:03:38의 운영 안내는 PT 슬라이드를 기본으로 준비하고 데모 영상 등을 붙일 수 있다고 한다. 영상은 허용이며 의무 길이·파일 형식은 확인되지 않았다.

2주차 강사는 팀 VM에 Ollama·ChromaDB·GraphDB를 미리 준비하라고 지도한다(01:39:28–01:39:59, 02:26:54–02:27:12). 동시에 GPT/Claude 사용도 가능하다고 설명하고(02:08:06–02:09:38), 최종 예제는 ChromaDB만 쓴다(05:05:01). 교실 준비 지시를 공식 제출 자격으로 확대하지 않는다. 본 권장안이 GPU VM 경로를 택하지 않는 이유는 권한·quota·준비시간·재현성 제약이며, 팀은 강사/운영진에게 대체 구성을 확인해야 한다.
