# 11/25 발표 데모 실행 대본

[#12의 기존 대본](https://github.com/GunP4ng/resource-ai/issues/12#issuecomment-7033340614)을 2026-11-21 `main` (`bc78e0845152f3b895300bd03509f2b3d4be6552`)의 실제 로컬 앱 화면에 맞춰 정정했다. 아래 화면 6장은 같은 버전에서 새로 촬영한 합성 텍스트 사례다. 사진과 외부 모델 호출은 사용하지 않았다. 이 문서는 시연 절차이며 현장 판정·허가·실측 성과의 증거가 아니다.

## 준비

저장소 루트에서 `bun install --frozen-lockfile --ignore-scripts` 후 다음을 실행한다.

```sh
bun run app
```

브라우저에서 `http://localhost:3000`을 연다. 기본 익명 앱은 재시작하면 사례를 복구하지 못하므로 발표 전에 입력을 연습하되 저장된 화면은 백업 자료로 명시한다. 두 사례 모두 **평가 기준일 2026-11-25, 발생 공정 사출, 수지 PP, 발생 지역 울산**을 합성 가정으로 사용한다. 사진은 첨부하지 않는다.

시연 전 senpi에서 구독 계정에 로그인한다. 앱은 실제 구독 모델로 검토한다. 아래 캡처는 이전 버전의 화면 기록이다.

## 정상 추천 · 약 3분

1. 오염 상태 **없음**, 유해물질 접촉 **없음**, 질량 **공란**으로 둔다. 설명에는 `합성 시연 — PP 사출 부산물 예시. 질량 미상, 오염 없음, 접촉 없음, 울산은 데모 가정입니다.`를 입력하고 **사례 제출**을 누른다. 질량 공란을 0 kg이나 100 kg으로 바꾸지 않는다. [입력 화면](01-input-no-mass.png)
2. 먼저 **추천 · 공개 근거상 가능한 경로 / 기계적 재활용 추천**이 나온다. 추천과 다음 행동 바로 아래에 **질량을 입력하면 비용·탄소를 계산해요 (선택)**가 접힌 영역을 열지 않아도 보인다. 이어 **이 사례의 6단계**에서 식별·분류는 `자료 있음`, 재활용 가능성·규정 검토·처리 방안은 `일부 자료`, 업체 탐색·비용·탄소는 `미확보`임을 보여준다. **판단 이유·자료 범위 확인하기**를 열면 낮은 확신도, 로컬 실행, 비용·탄소 미산정 사유도 확인할 수 있다. 질량만 추가해도 견적·탄소 계수가 없다면 수치를 만들어 내지 않는다. [추천·선택 질문·6단계](02-recommendation-optional-mass.png)
3. **판단 이유·자료 범위 확인하기**를 연 뒤 **근거 확인하기**를 눌러 **출처와 원문 위치**에서 폐기물관리법 시행규칙과 별표 4의 51-03-01, 별표 4의2의 R-3-3, 시행본 `lsiSeq=291947`을 보여준다. 원문 링크와 해당 조항·PDF 위치를 구분한다. [근거 화면](03-legal-evidence.png)
4. **실행 전 확인하기**를 눌러 현행 허가·업체 실제 인수·실측 질량·견적·탄소 경계·현장 승인 등 아직 필요한 확인을 보여준다. 추천은 반출·계약 승인이나 비용·탄소 우월성 판정이 아니다. [확인사항 화면](04-preexecution-checks.png)

## 유해 접촉 차단 · 약 2분

새 사례에서 같은 날짜·공정·수지·지역, 오염 상태 **없음**, 질량 **100 kg(합성 가정)**을 입력하되 유해물질 접촉을 **있음**으로 선택한다. 설명은 `합성 차단 시연 — PP 사출 부산물에 유해물질 접촉이 있다고 명시한 가상 사례입니다.`로 한다. **사례 제출** 후 **검토 필요 · 실행 보류**, 접촉 물질의 SDS·시험 자료를 먼저 확보하라는 다음 행동, 화면에 바로 표시되는 **보류 사유와 필요한 확인**을 보여준다. 조건별 대안은 확인해야 할 가정이지 실행 승인이나 확정된 지정폐기물 분류가 아니다. [차단 화면](05-hazardous-hold.png)

## 추가 정보 질문 · 별도 장면

새 사례에서 날짜·공정·수지·지역은 동일하게, 질량은 **100 kg(합성 가정)**, 유해물질 접촉은 **없음**으로 두고 **오염 상태에 `모름`을 명시**한다. 설명은 `합성 질문 시연 — PP 사출 부산물의 오염 상태는 모름. 유해물질 접촉은 없음이며 질량 100 kg, 울산은 데모 가정입니다.`로 한다. **사례 제출** 후 **추가 정보 필요 · 실행 보류**, **답변 입력하기**, 바로 아래 **보류 사유와 필요한 확인**에 표시된 질문을 보여준다. 질문은 이전 내용물·접촉 물질명·SDS 및 잔류물·세척 확인 자료를 요구한다. 모르는 오염 상태가 확인되기 전에는 조건부 대안을 현재 추천으로 소개하지 않는다. [추가 질문 화면](06-unknown-contamination-question.png)
