## 단일 운영 경로 확인

H 경로는 원장, private-file guard, 독립 recovery supervisor와 retention
책임을 포함한 명시적 공급자 계약이 필요하다. 콜백 없이 H를 선택하거나
O journal 설정과 H 주입을 함께 지정하면 시작하지 않는다. 임의 환경변수
모듈 로더나 샘플 금융 공급자를 운영 기본값으로 제공하지 않는다.

실제 QA는 private 디스크 SQLite와 H 감사 저장소, **테스트 전용 원장과
합성 transport**로 수행했다. 같은 입력의 네이티브 폼 재평가는 버전2를
저장했다. 변경된 미승인 입력은 거부했고 기존 버전2를 복구할 수 있었다.
종료 후 파일을 읽어 예약1건·정산1건, start/dispatch/finish 감사 각1건과
O 원장 파일 미생성을 확인했다. 이것은 이중 처리 방지의 기술 증거이며
실제 금융 정산·제공자 실행의 인수 증거가 아니다.

종료와 재적재는 반환된 짧은 timeout 결과뿐 아니라 실제 예약·감사·전송·
복구 콜백 및 H 내부 후속 작업이 끝나는 것을 기다린다. 해제되지 않는
작업을 둔 채 파일을 닫지 않으며, 프로세스 강제 종료 후에는 독립 supervisor가
복구를 담당한다. 상세 API와 책임은 [운영 인계](o-operational-handoff.md)에 있다.

## 실제 자료와 후보 인계의 구분

- `data/photo-archives/`는 원본 ZIP을 포함하지 않는 목록이다. 7개 ZIP의
  사진700개에 대해 접근 위치·보관기간·승인 등이 미확정이다.
  이 목록을 자동 설치, 모델 전송, 현장 사례 또는 독립 정답으로 사용하지 않았다.
- H는 `data/h-candidates/2026-11-12/`에 별도의 합성 입력·정제 공개 사진과
  출처 자료를 인계했다. 원본700개 목록과 별개이며, 국내 현장 사실이나
  독립 정답·split 승인으로 취급하지 않는다.
- O 후보는 `data/candidates/oyeonseok-2026-11-10/`에 있다.
  O와 H 후보가 존재한다는 사실은 30건의 중복 제거·독립 라벨·18/12 분리
  완료를 뜻하지 않는다. 수집자 외 검토 및 팀장 배정이 필요하다.
  특히 H 후보10건에 대한 **오연석의 독립적인 사람 검토**는 남아 있다.
  이 구현의 AI 코드 검토·합성 QA를 해당 독립 검토 대신 제출하지 않는다.
- 실제 field package와 승인된 provider/account/model/purpose·한도,
  실제 request ID·usage·사진 동의·철회/만료 인수 증거는 아직 미제공이다.

## 제출 판단의 경계

최종 부모 환경 전체 검사는 **753 pass / 0 fail, 35개 파일**이다.
타입검사·extension/app 빌드와 공식 offline smoke를 통과했다. 최초 전체
실행에서는 자식 앱 로그인503 두 건과 journal 시간 경계 실패 한 건이
있었다. 테스트 전용 프로세스 시각 인계를 명시하고, 미래 시각 거부 및
실제 deadline·TCP·SIGTERM 동작을 유지하는 회귀로 검증했다.
생산 인증 시계나 미래 시각 거부 조건은 변경하지 않았다. 최초 실패 로그에
시계 snapshot이 없어 그 시점의 모든 내부 상태를 복원했다고 주장하지 않는다.
Astra 최종 게이트는 변경된 전체 소스·테스트·담당 재대조와 실제 QA 증거를
검토하고 이번 기술 구현을 승인했다. 공식 offline smoke도 부모 환경에서
source/built extension, SDK 선택, 자원 정리까지 exit0으로 완료했다.

이번 PR은 O4의 현재 구현 가능한 공급자 선택·연결과 기술 검증을 제출한다.
실제 원장·파일 guard·독립 supervisor·retention 승인과 현장 자료를
받기 전에는 H 운영 인수를 완료로 바꾸지 않는다.
실제 승인·현장·금액·독립 라벨을 대신 작성하지 않으며 **#12는 열어 두고
#8은 재개하지 않는다**. 팀장 통합 QA·잠금 평가·영상·최종 보고서는 별도다.
