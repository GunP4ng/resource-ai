2026-11-12로 기록한다. 같은 `versionFamily`에서 평가일에 유효한 한 버전만
조회하므로 구 시행본의 보류 이유가 신 시행본 결과에 섞이지 않는다. 최초

## 2026-11-15 현행성 재확인

2026-11-15 04:59 UTC에 [현행 한글주소](https://www.law.go.kr/법령/폐기물관리법시행규칙)를
다시 조회했다. 현행 표시는 `lsiSeq=291947`, 시행일 2026-11-12,
기후에너지환경부령 제70호였고, 구 `lsiSeq=290881`은 비현행으로 표시됐다.
[291947 공식 본문](https://www.law.go.kr/LSW/lsInfoR.do?lsiSeq=291947&efYd=20261112)에서
제4조의2 제1항과 위 표의 네 `flSeq` 링크를 확인했다. 같은 링크의 PDF 네 건을
다시 받아 SHA-256을 계산한 결과 위 표의 보존 원본 해시와 모두 일치했다.
구 시행본도 [290881 공식 본문](https://www.law.go.kr/LSW/lsInfoR.do?lsiSeq=290881&efYd=20261002)의
제4조의2와 네 별표 링크, PDF 원본 SHA-256 일치를 확인했다.

구 시행본의 적용 종료는 11/11이다. 팀장 #57에서 구 인용 6건과 연결
고시 1건의 문구가 현행에도 유지됨을 11/14 확인한 `verifiedThrough`와
`verificationNote`는 보존한다. 구 인용의 확인일 11/14는 구 시행본의
적용을 11/14까지 연장하지 않는다. 현행 291947의 선택 조문·별표
`verifiedThrough`는 실제 재확인일 11/15까지만 갱신한다.
11/16 이후 평가일에는 다시 `currentness-unverified`로 보류한다.
기존 발췌 바이트·원본 SHA·`retrievedAt`·최초 인용 검토 시각은
재확인 시각으로 둔갑시키지 않는다. 이는 선택 인용의 현행성 확인이며
실제 사업장·시설·허가나 사례별 적합성 확인은 아니다.
