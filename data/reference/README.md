# 원문 스냅샷

`keco-price-2026-10.csv`는 한국환경공단의 [재활용가능자원 가격조사](https://www.data.go.kr/data/3076421/fileData.do)에서 2026-11-05에 내려받은 2026년 10월 원본 파일이다. 공공누리 제1유형(출처표시) 자료이며, 수치는 원/kg의 참고 매각가격이다. 처리수수료나 실제 계약 견적으로 사용하지 않는다. 파일 해시와 조회 상태는 `data/sources/manifest.json`에 기록한다.

`ulsan-processors-2025-12.sanitized.csv`는 울산광역시 원본 3,464바이트를 2026-11-05에 다시 내려받아 SHA-256 `794b619d7e0606ded9ebe447bb226fcebdbc442efeed69f625296f3fe39c68ed`와 일치한 뒤, `대표자`와 `전화번호` 열을 제거한 UTF-8 파생본이다. 파생본의 SHA-256은 `e6f7b9509db39006af30fe124a28d724a753a9ade2b7aec4c96d878362205bfc`이며 31개 업체 행이 있다. 원본에는 개인정보가 있어 배포하지 않는다. 이 목록은 업체 등재 사실만 보여주며 허가 코드·행별 갱신일·현재 인수 의사는 없다.
