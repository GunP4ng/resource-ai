# 확장 재질 실제 구독 실행

기준 main `24578438ceb49ad651d8a664d9c88d970782ca8f`에서 앱 기본 subscription runner와 사용자가 지정한 단일 구독 계정으로 실행했다. 정상 금속·위험 금속·목재의 세 합성 입력을 실행 전에 정했고 각 입력을 한 번 제출했다. 앱 기본 gpt-6-sol, 최대3턴, 요청 제한시간을 변경하지 않았다.

세 사례는 모두 저장됐고 실제 제공자 요청은6회(HTTP200 6회), 재시도0회다. 정상 금속·목재는 compared/validation-passed, 위험 금속은 needs-review/not-evaluated다. 위험 사례는 선행 호스트 안전 규칙이 추천을 중단한 결과이며 모델 제안을 거부한 것처럼 연출하지 않았다.

세 모델 출력은 모두 호스트가 발급한 판정 참조를 선택했다. 실제 모델·도구 실행 및 검증 기록이며 독립적 모델 기여나 정확도 향상 증거가 아니다. 원래 입력·판정 revision과 제공자 응답 식별자를 저장 기록과 대조했다.

- inputs.json: 실행 전 선택한 세 입력.
- cases.json: 저장된 입력, 판정, 실행 메타데이터, 단계별 모델 제안/호스트 선택/검증, 검증 계획의 원본 필드. 비공개 저장소의 소유자·세션 관리 필드만 제외했다.
- requests.jsonl: 계정·endpoint 일치 확인 뒤 기록한 실제 요청/응답. 인증 헤더·쿠키는 저장하지 않았다.
- summary.json: 상태·검증·사용량 요약과 해석 한계.

보고된 토큰 수는 비용이 아니다. 업체 인수·견적·현장 효과·Azure 성공을 입증하지 않는다. 이후 표시 문구 변경과는 별도로 위 실행 커밋에 결속된 기록이다.
