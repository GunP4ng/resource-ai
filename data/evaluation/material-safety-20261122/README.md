# 재질 안전 합성 고정셋

철·비철·목재·종이·복합 포장재의 기존 60건에 일반 잔류 표현 68건을 추가한 128건 고정셋이다. 기존 60건의 입력·기대값은 유지했다. 노출된 합성 개발 입력이며 현장 정확도, 법적 분류의 확정, 미관측 입력에 대한 안전성 보장을 뜻하지 않는다. 기존 플라스틱 18건과 별도로 집계한다.

- `inputs.json`: 전체 입력, 재질군, 조건, 기대 상태와 필요한 안전 사유 키.
- `manifest.json`: 입력 파일 원본 SHA-256과 각 입력의 `revision` 해시. 정렬 직렬화는 `src/o-validation.ts`를 사용한다.
- 전체 기대 상태: 조건부 추천 45건, 추가 정보 필요 63건, 검토 필요 20건. 기존 60건은 14/27/19를 유지한다. 기대값은 수정 전 선언했으며 실행 결과에서 추출하지 않았다.
- 재질별로 깨끗함, 위험 긍정, 명시 부정, 양방향 혼합, 미인식 오염·잔류·처리 이력을 포함한다. `납으로`, `땜납`, `도금된`, `방부목`, `PCB 함유`, 전각 PCB와 무도금·납품·납작 대조 입력을 포함한다.
- `RESIDUE-` 68건은 `61b6fab` 기준의 후속 사례다. 막·잔여물·찌꺼기·얼룩·부착물·묻음·끈적·슬러지·분진·이물의 설명/공정/오염 입력과 각 명시 부정을 포함한다. 리드의 `합성 구리 스크랩, 끈적한 막`, 혼합·다른 칸 부정·알려진 위험 우선·납품/수납 대조도 포함한다.

```sh
bun scripts/measure-guidance.ts --out /absolute/path/to/new-evidence-directory
bun test --timeout 30000 ./tests/material-safety.test.ts
```

측정은 기존 18건의 원본 해시와 전체 판정 불변을 먼저 확인한다. 새 고정셋의 결과는 `material-safety.json`, 별도 집계는 `summary.json`의 `materialSafety`에 기록한다. 입력 해시 또는 기대 판정이 다르면 실패하며 기존 출력 디렉터리는 덮어쓰지 않는다. 구현 해시 목록에는 `src/material-context.ts`도 포함한다.

기준 `f06281e`에서 36건이 기대와 일치하고 24건은 불일치했다. 불일치는 추천 누출 18건, 명시적 부정의 오보류 1건, 필요한 오염 질문 부재 3건, 질문 대신 인용 부족 보류 2건이었다. 기준 실행과 수정 후 결과의 위치 및 변화 표는 PR에 기록한다.

설명·공정의 기본 질문은 명시적 잔류·오염·처리 신호가 부정문 제거 뒤 남았을 때 적용한다. 일반 발생원 설명 전체를 오염으로 취급하지 않으며, 등록되지 않은 모든 유해 표현을 이해하는 자연어 분류기는 아니다. 알려진 위험 긍정과 구조화된 유해 접촉은 질문보다 안전 보류를 우선한다.
